## Approach

Attach optional, lazy-loaded investigation activities to existing lessons through the book-owned `lab_kit.js`. Keep the original figures and lesson identities. Reuse tested subject models, drawing helpers and notebook storage. New subject-specific activities live outside the vendored engine. The existing investigation directory gains routes by purpose. Every activity has a short question, Explore/Investigate/Challenge modes, controls, a calculated picture, model limits, sources, a repeatable case, comparison and evidence capture where meaningful.

## Checks

Focused checks run at the public model/record boundaries and through the built reader's activities. Known numerical examples, conservation, geometry, deterministic cases, invalid values and evidence persistence are checked locally. Rendered checks cover each added activity in default and meaningful changed states on phone and desktop; notebook/export, keyboard, no autoplay, lifecycle, offline and local-only storage are exercised. Independent fresh reviewers check new scientific content, fidelity, age-appropriate explanation, safety and provenance.
